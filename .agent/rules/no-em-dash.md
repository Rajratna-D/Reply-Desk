# No Em Dashes

Never use em dashes (`—`, Unicode U+2014) anywhere in this repository.

## Rules
1. Do not use em dashes in code, docstrings, comments, UI text, prompt templates, or error messages.
2. Do not use em dashes in documentation, build logs, markdown files, PRDs, or architecture notes.
3. Use a standard ASCII hyphen (`-`), colon (`:`), or comma instead.
