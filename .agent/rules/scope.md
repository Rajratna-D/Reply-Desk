# Rule: keep scope small

This is a 5-day build for a hackathon challenge. Out of scope unless the user explicitly asks:

- Login, accounts, multi-user support, cloud hosting
- WhatsApp or Instagram integration, auto-sending
- Payments, orders, inventory sync, analytics dashboards
- Image understanding
- Embedding models or vector databases (use the whole catalogue in the prompt; FTS5 is the stretch option)

Work one milestone at a time from `docs/TASKS.md`. If something is ambiguous, ask instead of guessing.
